> Stitching Excel, Access, and WhatsApp into one correlated view for small businesses.

**Built for Kiroween 2026 Hackathon** | Category: Frankenstein | Solo Project

## 🎯 What is ChimeraFlow?

Small businesses don't run on APIs. They run on **Excel spreadsheets**, **Access databases**, and **WhatsApp groups**. ChimeraFlow brings these disconnected data sources together through intelligent correlation rules written in plain French or English.

**Demo Scenario:** ZOBO Hardware Store (Douala, Cameroon)
- **Access database** (`STOCK.mdb`) — Legacy inventory (Articles, Mouvements)
- **Excel spreadsheet** — Supplier price lists (imperfect formatting, accents missing)
- **WhatsApp export** — Customer orders group (French/English mix, abbreviations)
- **Mobile Money CSV** — Payment confirmations (generated by Kiro Crew during demo)

**Key Innovation:** Handles the same product written four different ways (`ciment 50 kg`, `Ciment50kg`, `cimént 50kg`, `ciment (50kg)`) through linguistic normalization powered by LinguaSolution's NLP expertise.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/lefredoo/ChimeraFlow.git
cd ChimeraFlow

# Frontend (Next.js)
cd frontend
npm install
cp .env.example .env.local
# Edit .env.local with your configuration
npm run dev  # http://localhost:3000

# Backend (FastAPI)
cd ../backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your configuration
uvicorn main:app --reload  # http://localhost:8000
```

**Important:** All data in this demo is **100% synthetic**. No real phone numbers, no real messages.

## 🔧 Key Features

### 1. Multi-Source Data Correlation
- Unified record schema across all sources
- Linguistic normalization (FR/EN, accents, case, whitespace)
- Provenance tracking (every correlation shows source origin)

### 2. Declarative Rule Engine
- Rules in plain French/English converted to JSON via LLM
- No code execution (safe, deterministic)
- Visual rule editor + predefined templates
- Budget-capped LLM usage with fallback to predefined rules

### 3. MCP Connectors (Model Context Protocol)
- Excel parser (handles merged cells, imperfect formatting)
- Access reader (`.mdb` support via mdbtools/access_parser)
- WhatsApp export parser (Android/iOS formats, multilingual)
- Mobile Money CSV (generated by Kiro Crew in demo)

### 4. Property-Based Testing
Using Hypothesis to guarantee:
- Provenance conservation
- Normalization idempotence
- Parser round-trip correctness
- Determinism
- Window monotonicity
- No data fabrication

## 🛠️ Development

### Prerequisites

- Node.js 18+ (frontend)
- Python 3.11+ (backend)
- Redis (rate limiting)
- Docker (optional, for local deployment)

### Environment Variables

See `.env.example` files in `frontend/` and `backend/` directories.

**Key variables:**
- `LITELLM_API_KEY` — LiteLLM virtual key
- `LITELLM_BUDGET_USD` — Budget cap (default: 5.0 ≈ 3,300 FCFA)
- `REDIS_URL` — Redis connection for rate limiting
- `CORS_ORIGINS` — Allowed origins (comma-separated)
- `DATA_DIR` — Path to synthetic data files

### Available Scripts

**Frontend:**
```bash
npm run dev       # Development server
npm run build     # Production build
npm run lint      # ESLint
npm test          # Tests
```

**Backend:**
```bash
uvicorn main:app --reload  # Development server
pytest                     # Run tests (including PBT)
pytest --hypothesis-profile dev  # Quick PBT (fewer iterations)
```

## 🤖 Kiro Usage

ChimeraFlow extensively uses Kiro throughout development:

1. **Specs** — 4 distinct specs (connectors, rule-engine, ui, api) drive structured implementation
2. **Kiro Crew** — 3 custom agents:
   - `chimera-builder` — Generates new data connectors
   - `test-warden` — Writes property-based tests
   - `rule-smith` — Assists with rule DSL design
3. **Hooks** — Automated workflows:
   - On parser save: run contract tests + PBT
   - On spec modification: reminder to update tasks
   - On rule creation: validate schema
4. **MCP Servers** — 4 connectors registered in `.kiro/settings/mcp.json`
5. **Property-Based Testing** — 6 core properties verified with Hypothesis

See write-up in submission for detailed analysis of Kiro's impact.
