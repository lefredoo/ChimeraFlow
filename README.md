# ChimeraFlow

> Stitching Excel, Access, and WhatsApp into one correlated view for small businesses.

**Built for Kiroween 2026 Hackathon** | Category: Frankenstein | Solo Project | Phase P0 Complete ✅

---

## 🎯 What is ChimeraFlow?

Small businesses don't run on APIs. They run on **Excel spreadsheets**, **Access databases**, and **WhatsApp groups**. ChimeraFlow brings these disconnected data sources together through intelligent correlation rules written in plain French or English.

**Demo Scenario:** ZOBO Hardware Store (Douala, Cameroon)
- **Access database** (`STOCK.mdb`) — Legacy inventory (Articles, Mouvements)
- **Excel spreadsheet** — Supplier price lists (imperfect formatting, accents missing)
- **WhatsApp export** — Customer orders group (French/English mix, abbreviations)
- **Mobile Money CSV** — Payment confirmations (generated by Kiro Crew during demo)

**Key Innovation:** Handles the same product written four different ways (`ciment 50 kg`, `Ciment50kg`, `cimént 50kg`, `ciment (50kg)`) through linguistic normalization powered by LinguaSolution's NLP expertise.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Python 3.11+
- Redis (or Docker)
- Doppler CLI (optional, for secrets management)

### Setup

```bash
# Clone the repository
git clone https://github.com/lefredoo/ChimeraFlow.git
cd ChimeraFlow

# Copy environment template
cp .env.example .env
# Edit .env with your values

# Install backend dependencies
cd backend
pip install -r requirements.txt
cd ..

# Install frontend dependencies
cd frontend
npm install
cd ..

# Generate synthetic data
python scripts/generate_whatsapp.py
# Excel generation requires: pip install pandas openpyxl
python scripts/generate_excel.py
```

### Run (Development)

**Option 1: Docker Compose** (Recommended)
```bash
docker-compose up -d
# Frontend: http://localhost:3000 (run separately with npm run dev)
# Backend: http://localhost:8000
# API Docs: http://localhost:8000/docs
```

**Option 2: Manual**
```bash
# Terminal 1: Backend
cd backend
python main.py  # or: uvicorn main:app --reload

# Terminal 2: Frontend
cd frontend
npm run dev

# Terminal 3: Redis (if not using Docker)
redis-server
```

**Important:** All data in this demo is **100% synthetic**. No real phone numbers, no real messages.

## 🔧 Key Features

### 1. Multi-Source Data Correlation
- Unified record schema across all sources
- Linguistic normalization (FR/EN, accents, case, whitespace)
- Provenance tracking (every correlation shows source origin)

### 2. Declarative Rule Engine
- Rules in plain French/English converted to JSON via LLM
- No code execution (safe, deterministic)
- Visual rule editor + predefined templates
- Budget-capped LLM usage with fallback to predefined rules

### 3. MCP Connectors (Model Context Protocol)
- Excel parser (handles merged cells, imperfect formatting)
- Access reader (`.mdb` support via mdbtools/access_parser)
- WhatsApp export parser (Android/iOS formats, multilingual)
- Mobile Money CSV (generated by Kiro Crew in demo)

### 4. Property-Based Testing
Using Hypothesis to guarantee:
- Provenance conservation
- Normalization idempotence
- Parser round-trip correctness
- Determinism
- Window monotonicity
- No data fabrication
